# Three-tap run provenance

CelebA-HQ was excluded from every split and patch cache before training. Other sources were retained at the author's direction. The exclusion removes this dataset from the new experiment; it is not a blanket commercial-rights verification. Large uses no previous detector weights or teacher targets.
